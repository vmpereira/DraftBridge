# Getting Started for Developers

How to set up and run DraftBridge locally.

## Prerequisites

- Node.js >= 20
- npm or pnpm

## Development Workflow

1. Install dependencies:
   `ash
   npm install
   `
2. Run test suite:
   `ash
   npm test
   `
3. Run desktop app in development:
   `ash
   npm run dev
   `
4. Build static export and desktop binaries:
   `ash
   npm run build
   `
